# Conduit downloads

Signed Conduit CLI packages for macOS Apple Silicon.

Development builds are published as prereleases. After the initial dev update, use `conduit update --channel dev`. Older CLIs can use the exact `conduit update --version ...` command in the selected release notes. Plain `conduit update` selects the stable channel when a stable release is available.

These are development builds; physical glasses acceptance remains a separate attended check. Source development is maintained separately.
